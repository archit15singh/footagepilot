# Planned native title scale and weight

Verified12November2026 on freeResolve21.2.0.6. Native TextPlus already supported size/weight; the visual planner now exposes those controls.

Resolve plans return integer `title_size` and boolean `title_bold`, shared by the main title and every progressive title line. Optional spec `title_sizes` supplies1–10unique integers8–72; default choices are `[28,40,56]`. Old recorded plans without these fields retain28/regular. Font families still come from `title_fonts`. Edits planning remains28/regular and rejects unsupported selections. The compiler preserves these settings into the native job; assembly reads back Font, Style, Size and StyledText before saving/rendering. These are native parameter checks, not proof that every installed font has a particular typeface or a pixel-exact reference match.

Optional `reference_times: [1.0]` adds up to two focus timestamps to distributed change-neighbour samples. Each selects the nearest already-extracted frame and retains its actual timestamp/ID; it does not invent an exact frame at the requested time. Planning and reference review both receive the extra images and hashes. This is useful for a title, held composition or other important region missed by change-focused sampling. The total reference image bound is20; observations still require citations and temporal uncertainty.

The live run supplied the reference’s1-second bold gold title frame explicitly. Codex chose40/bold Baskerville and generated an actual13.5-second native Resolve movie/DRP. The same word “Follow” occupied101×23pixels at320-wide QA sampling, compared with60×17pixels in the prior28/regular render. Both were on black and sampled before the second line entered. This establishes a typography change, not a controlled whole-film quality improvement; shot/timing decisions also changed. See RESULTS.md and `evals/results/planned-typography.json`.

Title timing QA retains conservative bands. Larger simultaneous titles can make some entry/exit samples ambiguous even when the rendered glyphs are visibly separated. Those samples are labelled ambiguous, not passed; do not describe the film as exhaustively timing-verified. Inspect both title states in playback and retain the limitations. Size/readback checks do not judge text taste, emotional fit, OCR correctness or human preference.
