# SpliceForge build plan

Local video editing workbench for creators and coding agents. Tagline: Make the cut. Show the evidence.

1. Project contract and CLI: import footage, explicit keep ranges, captions, brand settings; validate before rendering; deterministic exports and decode evidence.
2. Editing pipeline: local transcription, transcript-based cleanup and review; storyboarded motion graphics via Remotion, optional HyperFrames; shared audio and compositing. Reuse benchmark findings, not benchmark-specific paths or scripts.
3. Workbench: project creation, transcript and storyboard review, job status, output playback and branding revisions. Bind locally; validate requests and restrict file serving.
4. Evaluations: narrated demo plus realistic retakes, caption overflow, broken media, invalid edits, revision invariants and failed-job recovery. Include negative controls and human-readable qualitative review.
5. Release: reproducible setup, agent guidance, public repository, evidence and limitations. Verify fresh setup, CLI and browser flow before completion.

Completion requires working end-to-end output from the product itself, not merely the precursor benchmark. Synthetic footage cannot establish storytelling judgment. Audio playback and human taste review must be distinguished from decode/level checks.
