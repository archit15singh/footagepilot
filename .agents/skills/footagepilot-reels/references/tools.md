## Google Photos download fallback

When the official Download action fails in an automation-controlled tab, open the same search or item in a fresh Brave tab and use native app computer control for the entire download. Use the signed-in profile, open the item, and choose **More options → Download**. A single original video downloaded successfully this way after the automated tab blocked the download host. The precise blocking component was unconfirmed.

Verify a new local file appeared, then probe its duration and dimensions and decode it before editing. Preserve the original in ignored project storage. If the library export still fails, use local originals or another approved handoff.
